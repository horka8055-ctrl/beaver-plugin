# BeaverPlugin

Плагин для Paper **1.21.11**, добавляющий:

1. **Моба-бобра** с кастомной 3D-моделью (пухлое тело, уши, глаза, зубы,
   короткие лапы, широкий плоский хвост) — требует ресурспак
   `BeaverDamResourcePack` (см. ниже), иначе бобёр виден как обычный предмет.
2. **Плотину на реках** — настоящая NBT-структура (`dam.nbt`), которая
   вставляется при первой генерации чанка с биомом `RIVER`
   (шанс `DAM_CHANCE_PER_CHUNK`, по умолчанию 2%). Рядом с плотиной
   автоматически спавнится бобёр.
3. **Поведение бобра**: раз в 10-20 минут (случайно) бобёр находит ближайшее
   дерево в радиусе 12 блоков, идёт к нему, "рубит" (ломает все связанные
   блоки бревна), а один блок бревна не выпадает предметом — бобёр его
   "съедает" (спецэффект + звук).

## Три составные части

| Часть                    | Обязательна?                         | Что делает |
|---------------------------|----------------------------------------|------------|
| `BeaverPlugin.jar`         | Да                                     | Вся логика: спавн, ИИ, вставка структуры |
| `BeaverDamResourcePack`    | Нет технически, но нужен для визуала   | Кастомная 3D-модель бобра вместо предмета-заглушки |
| `BeaverDamDatapack`        | Нет, опционально                       | Та же структура `dam.nbt`, доступная через `/place template` и структурные блоки |

`dam.nbt` уже зашита прямо в `BeaverPlugin.jar` (`src/main/resources/structures/dam.nbt`),
поэтому структура плотины работает даже без отдельного датапака.

## Сборка плагина

Нужны Java 21+ и Maven.

```bash
mvn clean package
```

Готовый файл: `target/BeaverPlugin.jar` — кладём в папку `plugins/` сервера Paper 1.21.11.

## Установка ресурспака (для кастомной модели)

Раздайте игрокам `BeaverDamResourcePack.zip` любым обычным способом
(`server.properties` → `resource-pack`, или через клиентские настройки).
Без него бобёр всё равно ходит/рубит деревья/спавнится — просто вместо
модели будет виден обычный предмет (кожаная попона).

## Установка датапака (опционально)

Положите `BeaverDamDatapack` в `world/datapacks/` и выполните `/reload`,
если хотите ставить плотину вручную командой `/place template beaverdam:dam ~ ~ ~`
или редактировать её через структурные блоки.

## Команды (право `beaverplugin.admin`)

- `/beaver spawn` — заспавнить бобра рядом с игроком.
- `/beaver dam` — попытаться построить плотину рядом (нужна вода поблизости).

## Визуал: как устроена кастомная модель

Чистый Bukkit/Paper API не позволяет зарегистрировать полностью новый тип
сущности со своей 3D-моделью без NMS/мода. Поэтому бобёр устроен так:

- **"Мозг"** — невидимый `Rabbit` (используется только ради готового ИИ,
  `Pathfinder`, коллизий и физики).
- **"Тело"** — `ItemDisplay`, посаженный на кролика пассажиром, показывающий
  предмет с кастомной моделью через `ItemMeta#setItemModel(NamespacedKey)`
  (официальный способ с 1.21.2+, без числового `custom_model_data`). Модель —
  полноценный набор из 15 кубов (тело в два яруса для округлости, голова,
  уши, глаза, нос, зубы, 4 лапы, плоский хвост) в
  `assets/beaverdam/models/item/beaver.json` ресурспака.

Форма модели ориентируется на низкополигональные voxel-модели бобра для
Minecraft, сделанные в Blockbench (по референсу пользователя — модель
"Beaver" от Monkeyhue на Sketchfab: 180 треугольников, cute/chonk/low-poly/
voxel). Сам файл модели скачать не удалось (Sketchfab не даёт скачивать чужие
модели без разрешения автора), поэтому геометрия — самостоятельно собранное
приближение в похожем стиле, а не копия. Подробнее и как доработать/заменить
на точную модель — см. README ресурспака.

Датапак (важное ограничение): начиная с 1.21.5 в Minecraft можно
data-driven переопределять текстуры некоторых мобов (корова/свинья/курица/
волк/кошка/лягушка) через "variants", но **для кролика такой системы нет**
("нельзя добавить кастомные варианты для лошадей и кроликов" — официальное
ограничение движка). Именно поэтому кастомная геометрия реализована через
ItemDisplay + ресурспак, а не через датапак.

## Ограничения / что можно доработать

- Поиск дерева — упрощённый (по кубу вокруг бобра, ищет блок бревна, стоящий
  на земле), не учитывает огромные (2×2) деревья.
- Плотина — простая по форме "из коробки"; редактируется через структурный
  блок (см. README датапака) без пересборки плагина.
- Модель и текстура бобра — собственное приближение "на глаз" к референсу
  (см. раздел "Визуал"); замените на точную в Blockbench, если нужно ближе
  к оригиналу (см. README ресурспака).

## Структура проекта

```
pom.xml
src/main/resources/plugin.yml
src/main/resources/structures/dam.nbt
src/main/java/ru/example/beaverplugin/
    BeaverPlugin.java      - главный класс, команды, конфиг-константы
    BeaverManager.java     - спавн бобра (невидимый Rabbit + ItemDisplay-модель)
    BeaverAI.java          - конечный автомат поведения одного бобра
    TreeUtils.java         - поиск дерева и его "валка"
    listeners/DamGenerator.java - вставка структуры плотины при генерации чанка-реки
```

## Самый простой способ собрать jar — без установки чего-либо (через GitHub)

Если не хочется ставить Java/Maven на свой компьютер, можно собрать jar прямо
в браузере через GitHub Actions:

1. Зайдите на https://github.com и создайте бесплатный аккаунт (если его ещё нет).
2. Нажмите зелёную кнопку **New** (или **+** → **New repository**) — создайте
   новый репозиторий, например с именем `beaver-plugin`. Оставьте его Public,
   ничего дополнительно не отмечайте, нажмите **Create repository**.
3. На странице пустого репозитория нажмите **uploading an existing file**
   (или "Add file" → "Upload files").
4. Перетащите в окно браузера **всё содержимое** папки `BeaverPlugin`
   (файл `pom.xml`, папку `src`, папку `.github` — всё, что внутри, а не саму
   папку `BeaverPlugin` целиком одним элементом). Нажмите **Commit changes**.
5. Откройте вкладку **Actions** вверху репозитория. Там должен появиться
   запуск с названием "Build BeaverPlugin" — подождите 1-3 минуты, пока
   рядом не появится зелёная галочка (значит, сборка прошла успешно).
6. Откройте этот запуск, пролистайте вниз до раздела **Artifacts** —
   там будет файл `BeaverPlugin-jar.zip`. Скачайте его, распакуйте —
   внутри будет готовый `BeaverPlugin.jar`.
7. Этот `.jar` файл кладёте в `plugins/` на сервере и перезапускаете сервер
   (stop/start, не `/reload`).

Если сборка на вкладке Actions покажет красный крестик вместо галочки —
откройте этот запуск и пришлите мне текст ошибки (там будет написано,
на каком шаге и почему не получилось) — я подскажу, что поправить.
